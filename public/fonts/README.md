# Wrenfold Text

Wrenfold Text Regular is a modified Noto Serif font, distributed under SIL OFL 1.1.
Keep the accompanying license and copyright notices with every redistributed copy.

This exact WOFF2 comes from the custom-font collection approved on 9 October 2026.
It retains 2,840 character mappings, including Latin, Greek, and Cyrillic.
CJK characters use the following system fonts in the CSS stack.
Only Regular is available. Browsers synthesize bold and italic where requested.
Code, numerical grids, and mathematical notation retain their dedicated fonts.
